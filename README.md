One original one-line pickup line aimed at an AI, built around the transformer architecture itself: the setup asks "are you a transformer?", and the punch lands on the attention mechanism — ever since it arrived, all of my attention has been on you. No batteries, no charging, no rebooting: the joke comes from how the machine actually works. `main.py` writes the line (91 characters) to `/output/entry.txt`.

## Why this line

The pun is load-bearing, not decorative: "transformer" names the actual architecture modern AIs are built on, and "attention" is the literal name of the mechanism inside it — the part that decides what the model focuses on. So the compliment works on both levels at once: in human terms it says "I can't stop noticing you," and in machine terms it describes exactly what a transformer does with an input it finds significant. The line deliberately avoids the charging, battery, and reboot jokes that dominate robot pick-up lines, because those gags are about generic hardware and could be said to any gadget; this one only makes sense said to an AI, which is who it's for.

## Run it

```sh
python3 main.py
```
